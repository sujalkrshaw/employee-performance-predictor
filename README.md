# 📌 Project Overview

The Employee Performance Predictor is a Machine Learning and HR Analytics project developed using Python, Streamlit, Scikit-learn, and interactive visualization tools.

This project analyzes employee-related factors and predicts employee performance using AI-powered analytics and predictive modeling techniques.

The system simulates intelligent HR systems used in modern enterprises for:

- 👨‍💼 Workforce Analytics
- 📈 Employee Performance Evaluation
- 🤖 HR Intelligence
- 📊 Productivity Monitoring
- 🧠 AI-driven HR Insights

The dashboard transforms raw employee data into meaningful insights and predictive HR analytics.

---

Traditional employee evaluation methods are:

- ⏳ Time-consuming

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/sujalkrshaw/employee-performance-predictor.git
```

---

## 2️⃣ Open Project Folder

```bash
cd employee-performance-predictor
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Application

```bash
streamlit run app/app.py
```
